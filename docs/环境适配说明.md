# 环境适配说明

> 本项目针对 **AYANEO AM02 + Bazzite-Deck** 这个组合踩过的环境坑，以及对应的修复方法。安装完 am02 服务后，**请务必阅读并完成本文的适配步骤**。

---

## 1. 关键适配：把默认输出从 eDP/DP 改成 HDMI（必做）

### 现象

- 切换「大屏模式 / 桌面模式」或切换分辨率时，**电视黑屏**。
- 机器**放一晚上**后，Steam 大屏界面（gamepadui）渲染进程丢失，重新切大屏就黑。
- 本地 HDMI 电视**也黑**（不是串流的问题，是 gamescope 本身没输出）。

### 根因

AM02 是一台 **mini PC，没有内置屏**，只有 HDMI 输出。但 Bazzite 的掌机版（gamescope-session-plus）默认启动参数是：

```
--prefer-output *,eDP-1
```

`eDP-1` 是**掌机的内置屏**接口。AM02 没有 eDP，于是 gamescope 每次启动/切换模式都要「找 eDP-1 → 找不到 → 回退 HDMI」，这个回退过程触发 HDMI 重握手，导致：

1. 切换模式瞬间黑屏；
2. 长时间运行后 gamepadui（Steam 大屏 UI）的渲染进程丢失。

所有掌机都有 eDP 内置屏，所以这个默认值对它们是对的——**只有「mini PC 硬跑掌机版」这种组合才会踩坑**。

### 修复

创建环境变量配置文件，让 gamescope 直接锁 HDMI：

```bash
mkdir -p ~/.config/environment.d
echo 'OUTPUT_CONNECTOR=*,HDMI-A-1' > ~/.config/environment.d/gamescope-output.conf
```

然后重启 gamescope 会话（或重启机器）：

```bash
systemctl --user restart gamescope-session-plus@steam.service
```

验证：gamescope 进程参数应变为 `--prefer-output *,HDMI-A-1`：

```bash
ps -eo args | grep '/usr/bin/gamescope ' | grep -v grep
```

> `OUTPUT_CONNECTOR=*,HDMI-A-1` 会在 gamescope 脚本 `source ~/.config/environment.d/*.conf` 时被读取，且早于默认值赋值，因此一定生效。

## 2. 4K 电视的分辨率边界

如果你的电视是 **4K**，gamescope 可能在实际输出 `1920x1080@60Hz`（非 4K）和 4K 之间跳变。建议固定输出分辨率，避免切换时重握手：

- 在 `gamescope-output.conf` 里可追加分辨率参数（如需要），或
- 在 Steam 显示设置里把外部显示器分辨率固定为 1080p。

> 串流（Moonlight/Sunshine）端一般非 4K，固定 1080p 通常最省心。

## 3. Sunshine 串流黑屏（可选，使用 Moonlight 时）

如果你用 **Sunshine + Moonlight** 串流这台机器，遇到过黑屏/鼠标不动：

- **根因**：Sunshine 是 user 服务，启动时没继承 gamescope 的 Wayland 环境变量（`WAYLAND_DISPLAY=gamescope-0`），抓屏连不上。
- **修复**：给 Sunshine 注入环境变量：

  ```bash
  mkdir -p ~/.config/systemd/user/app-dev.lizardbyte.app.Sunshine.service.d
  cat > ~/.config/systemd/user/app-dev.lizardbyte.app.Sunshine.service.d/override.conf <<'EOF'
  [Service]
  Environment=WAYLAND_DISPLAY=gamescope-0
  Environment=XDG_RUNTIME_DIR=/run/user/1000
  EOF
  systemctl --user daemon-reload
  systemctl --user restart sunshine
  ```

- **编码器**：如果 Vulkan 编码报错（`h264_vulkan Function not implemented`），在 Sunshine 配置里切到 software（libx264）编码。
- **广播名**：为避免局域网里多台 Sunshine 混淆，建议在 `~/.config/sunshine/sunshine.conf` 里固定：

  ```
  sunshine_name = AM02-bazzite
  ```

## 4. exfat 数据分区

副屏磁盘统计会对齐「所有已挂载数据分区」。安装脚本会挂载 exfat 分区（`UUID=3521-FB40` → `/var/mnt/exfat`，`nofail`）。如果你的机器分区 UUID 不同，请手动调整 `/etc/fstab`。

## 5. 常见问题排查

| 问题 | 排查 |
|------|------|
| 副屏黑屏/不刷新 | `systemctl status am02-service`，看是否 active；`ls /run/am02-service.sock` 是否存在 |
| TDP 档位无效 | `lsmod \| grep ryzen_smu`，未加载则 `sudo insmod /var/lib/am02-service/modules/ryzen_smu.ko` |
| 风扇转速为 0 | `sensors \| grep it86`，未加载则 `sudo modprobe it87 force_id=0x8620` |
| 天气不显示 | 插件里设置城市后，`journalctl -u am02-service -f \| grep 天气` 看拉取日志 |
| 插件打不开 | 重开一次 QAM；仍不行 `systemctl restart plugin_loader.service` |
